# 辅助漂移操控

当前为便于键盘和触控操作的辅助驾驶模型，不是实车轮胎或电子稳定系统仿真。车辆依然通过 Rapier 动态刚体、轮胎冲量与接地力矩移动，运行期间不直接修改速度、位置或姿态。

## 操作

- 弯前减速，转向并短按手刹起漂；键盘 Space、手柄 A、触控右侧手刹映射相同。
- 松开手刹后，油门维持后轮侧滑，方向控制路线与漂移角度。前轮会辅助反打跟随实际滑行方向，驾驶员仍能左右修正或连续接漂。
- 漂移中再次按下手刹，或踩脚刹，会进入收车辅助。后轮渐进恢复抓地，附加稳定力矩帮助车头回到滑行方向；此时手刹作为四轮制动辅助，不再锁死后轮扩大侧滑。按住不会反复切换模式。
- 松油、方向回中也会逐步结束漂移。低速、倒车与腾空不启用漂移转向或偏航辅助；重置清空整个控制状态。
- HUD 显示“收车辅助 · 恢复抓地”，漂移时触控按钮显示“手刹收车”。此二次按键语义是街机辅助设计，与真实车辆手刹的作用不同。

## 实现

`DriftController` 管理起漂 / 收车状态及平滑抓地倍率。手刹起漂最低后轮倍率 0.48；松手刹后油门可维持低抓地，松油恢复。再次按键或脚刹使抓地向 1 收敛，恢复阶段至少保留约 1.2 s，按住收车制动时延续；连续小角度稳定行驶退出起漂状态。

`VehiclePhysics` 在前进且至少三轮接地时，将侧滑角补偿加入前轮转向，并在漂移阶段减小驾驶员转向到轮角的比例，避免方向一打就持续甩尾。带限幅的偏航力矩跟随驾驶员转向和目标侧滑角；最大力矩 25,000 N·m，仅用于辅助驾驶状态，不等同于真实 ESP 制动力。普通驾驶仍使用原转向曲线和偏航阻尼。全部辅助在失去接地条件后停止。

## 验证

`tests/drift-control.spec.ts` 使用真实 Rapier 步进验证持续三秒以上的可控侧滑、左右输入改变实际位移、保持向前行驶、左右连续接漂，以及 40 / 60 / 90 km/h 下二次手刹与脚刹收车。原动力学回归继续覆盖正常过弯、倒车、腾空、落地与重置。

自动测试验证控制能力和边界，不能代替玩家对漂移节奏、力度和音色的主观评价。
