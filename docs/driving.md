# 辅助漂移操控

当前为便于键盘和触控操作的辅助驾驶模型，不是实车轮胎或电子稳定系统仿真。车辆依然通过 Rapier 动态刚体、轮胎冲量与接地力矩移动，运行期间不直接修改速度、位置或姿态。

## 操作

- 弯前减速，转向并短按手刹起漂；键盘 Space、手柄 A、触控右侧手刹映射相同。
- 松开手刹后，油门维持后轮侧滑，方向控制路线与漂移角度。前轮会辅助反打跟随实际滑行方向，驾驶员仍能左右修正或连续接漂。
- 低速、至少三轮接地时同时按住油门与脚刹会进入烧胎：前轮制动、后轮保持驱动并降低抓地，可配合方向键有限原地转圈。HUD 显示蓄力进度；松开脚刹时会在低速区间施加有限起步加力，速度达到上限后自然衰减。行驶中同按油门和脚刹不会烧胎，脚刹仍优先减速。
- 漂移中再次按下手刹，或踩脚刹，会进入收车辅助。后轮渐进恢复抓地，附加稳定力矩帮助车头回到滑行方向；此时手刹作为四轮制动辅助，不再锁死后轮扩大侧滑。按住不会反复切换模式。
- 松油、方向回中也会逐步结束漂移。低速、倒车与腾空不启用漂移转向或偏航辅助；重置清空整个控制状态。
- HUD 显示“收车辅助 · 恢复抓地”，漂移时触控按钮显示“手刹收车”。此二次按键语义是街机辅助设计，与真实车辆手刹的作用不同。

## 实现

`DriftController` 管理起漂 / 收车状态及平滑抓地倍率。手刹起漂最低后轮倍率 0.48；松手刹后油门可维持低抓地，松油恢复。再次按键或脚刹使抓地向 1 收敛，恢复阶段至少保留约 1.2 s，按住收车制动时延续；连续小角度稳定行驶退出起漂状态。

`VehiclePhysics` 先由车辆局部纵向与侧向速度计算侧滑角 `β = atan2(v侧, |v纵|)`。漂移时，前轮转角保留 30% 驾驶员基础输入，并叠加受限的 `β` 反打项；这让玩家决定过弯半径，反打只用于避免车辆持续自旋。偏航目标由驾驶员转向和目标侧滑角组成，偏航力矩按 `(目标偏航角速度 - 实际偏航角速度) × I_y` 计算并限幅，仍通过 Rapier 力矩而非直接改写姿态实现。持续手刹只部分切断后轮驱动力，保证能以油门维持漂移。烧胎使用前轮制动、后轮低抓地与受限偏航力矩；蓄力和弹射都只调整轮胎力与刚体力。普通驾驶仍使用原转向曲线和偏航阻尼。接地时另有受限的车身竖直姿态恢复力矩和横滚 / 俯仰角速度阻尼，降低护栏碰撞后的起跳与翻转；腾空时不施加该力矩，也不直接改写刚体速度或姿态。

## 验证

`tests/drift-control.spec.ts` 使用真实 Rapier 步进验证持续三秒以上的可控侧滑、左右输入改变实际位移、保持向前行驶、左右连续接漂，以及 40 / 60 / 90 km/h 下二次手刹与脚刹收车。`tests/dynamics.spec.ts` 另验证低速烧胎的有限原地转向、蓄力弹射和脚刹减速。原动力学回归继续覆盖正常过弯、倒车、腾空、落地与重置。

自动测试验证控制能力和边界，不能代替玩家对漂移节奏、力度和音色的主观评价。
