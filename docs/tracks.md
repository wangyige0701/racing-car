# 赛道与计圈

顶部选择器或横屏暂停菜单可切换赛道。切换会释放旧场景、物理世界、音频和 GPU 设备，重新加载所选路线；圈数与成绩重新开始。画质、音量、静音、当前视角和驾驶舱舒适设置会在本浏览器的本地存储中恢复。

## 共用道路数据

`src/track/catalog.ts` 定义名称、主题、宽度和三维控制点；`Track` 生成闭合 Catmull-Rom 中心线。试车场 240 个等距样点，其他路线各 720 个，路宽 16 m。道路网格、坡度方向、连续护栏、地图、重置位置和计圈门都使用同一份采样数据。

四条路线均包含左右交替转向，弯前 50 / 100 m 标牌根据路线曲率自动选择六个主要弯道。回绕路段保持间距，目前没有上下立交。

道路为 Rapier 三角网格碰撞面，护栏为沿坡度旋转的重叠圆角体，使用低摩擦、无回弹接触以降低高速碰撞时的卡边、起跳与穿透概率。重置将车辆放回赛道起点并对齐道路坡度。当前路线无上下重叠，最近点查询使用 XZ 平面距离，不支持立交层选择。装饰地形、海面、树木和建筑没有驾驶碰撞，均布置在护栏外；全路线几何检查验证地形网格低于路面。

## 计圈规则

- 起点加七个顺序检查点组成一圈，路边 CP 1～7 标牌与实际计圈门一致。50 / 100 m 标牌仅提示弯道距离。
- 第一次向前穿过起点开始计时，依次通过 CP 1～7 再过起点才记一圈。倒着过门、漏点后直接过起点、少于两轮接地或穿越高度不符均不推进检查点。
- 使用固定物理步进时间，并按穿门位置在步内插值；暂停、页面隐藏期间不计时。HUD 分别显示练习总时间、当前圈、上圈、最佳圈、有效圈数及下一检查点。
- 离开道路横向范围（半路宽加 1 m 容差）或单步异常位移使本圈无效；逆向持续超过 0.8 s 显示提醒。顺序门和位移校验用于本地练习正确性，不构成联网反作弊。
- 重置取消当前圈并清空检查点进度，保留本赛道本次会话的已完成圈数、上圈和最佳圈。回到起点重新通过即可开始新圈，重置本身永远不增加圈数。
- 无效圈按剩余检查点顺序回到起点后开始新圈，或重置后回到起点重新开始。

## 验证与边界

`tests/track.spec.ts` 验证道路闭合、高差、左右转向变化、非相邻路段净间距、整圈实际物理驾驶、重置接地、地形不穿路，以及顺序 / 逆向 / 腾空 / 离路 / 异常位移 / 重置的计圈行为。`tests/track-browser.spec.ts` 在实际 WebGPU Chrome 中连续切换四条路线，检查画布、控制台、驾驶舱画面、起点计时和重置；移动横屏入口由 `tests/mobile.spec.ts` 验证。

目前为自由练习与本次会话计圈。完整竞赛菜单、发车倒计时、AI 对手、固定圈数结算、成绩存档与排行榜均未实现。赛道结构与环境资产已完成第一轮写实化，仍需真实设备性能验收和后续美术精修。
