# APEX / 竞速实验室

高品质 WebGPU 赛车项目，已实现车辆动力学，并接入正式授权的 **Car Concept GLB 赛车、左舵驾驶舱、轮胎烟雾与驾驶音效**。在约 1.10 km 的松岭闭合试车场自由驾驶，支持手刹侧滑、渐进抓地恢复、悬挂防侧倾与四种视角。已新增山地、沿海和城市三条高差路线、赛道切换与顺序检查点计圈；完整竞赛流程尚未实现。

## 运行

需要 Node.js 20.19+（22.x 需 22.13+）、pnpm 11.18.0，以及支持 WebGPU、开启硬件加速的现代浏览器。开发使用 localhost / 127.0.0.1，正式部署使用 HTTPS。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端给出的本地地址，默认 `http://127.0.0.1:5173`。

```sh
pnpm build          # Vue / TypeScript 类型检查 + 生产构建
pnpm preview        # 本地预览 dist，默认端口 4173
pnpm test           # 物理、闭环驾驶、输入与真实 WebGPU 浏览器验收
pnpm format:check   # 格式检查
pnpm assets:environment # 从已下载的固定来源重新生成场景资产
```

测试默认使用已安装的 Google Chrome。使用 Edge 时在 PowerShell 设置 `$env:BROWSER_CHANNEL = 'msedge'` 后运行 `pnpm test`。测试会启动或复用 5173 端口的开发服务；本地请求不经过 HTTP 代理。没有 WebGPU 的环境会使实际渲染测试失败，不会跳过或回退 WebGL。

依赖使用精确版本和 `pnpm-lock.yaml` 固定。`pnpm-workspace.yaml` 管理工作区内的 `.pnpm-cache/`、`.pnpm-store/`，二者不纳入 Git。没有服务端、数据库、环境变量式游戏配置或外部模型 / 字体 CDN。`dist/` 可作为静态站点通过 HTTPS 托管，并应启用 gzip / Brotli。

## GitHub Pages 部署

`.github/workflows/deploy-pages.yml` 在推送到 `main` 或手动触发时，以 `pnpm build` 构建并发布 `dist/`。在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**；工作流会按 `/<仓库名>/` 设置 Vite 基路径，因此 JavaScript、GLB、纹理和图标可在项目页地址下加载。若部署到 `<owner>.github.io` 根站点或自定义域名，将工作流的 `VITE_BASE_PATH` 改为 `/` 后再发布。

## 驾驶操作

点击“操作说明”按钮，在弹出面板中查看键盘、手柄和触控提示；全屏和横屏也提供入口。打开时暂停驾驶，关闭按钮或 Esc 关闭面板后恢复原先的驾驶状态；打开前已暂停则保持暂停，恢复驾驶后需重新按下油门等按键。

| 操作               | 键盘             | 标准映射手柄 | 触控            |
| ------------------ | ---------------- | ------------ | --------------- |
| 加速               | W / ↑            | RT           | 按住加速        |
| 制动，停稳后倒车   | S / ↓            | LT           | 按住制动 / 倒车 |
| 转向               | A、D / ←、→      | 左摇杆       | 按住左右箭头    |
| 保持当前转向       | 按住左 Shift     | —            | —               |
| 手刹               | Space            | A（按钮 0）  | 按住手刹        |
| 循环切换视角       | C                | X（按钮 2）  | 顶部视角按钮    |
| 调低 / 调高音量    | [ / ]            | —            | 音量滑块        |
| 切换驾驶画面全屏   | F11              | —            | 全屏按钮        |
| 从赛道起点重新开始 | R / 重置车辆按钮 | Y            | 重置车辆按钮    |
| 暂停 / 继续        | Esc / 暂停按钮   | Start        | 暂停 / 继续按钮 |

- 输入有持续按下和释放状态，转向与油门经过平滑处理。低速保留较大转角，随车速平滑减小；普通转弯不会因侧滑检测自动削弱方向输入。松油后通过接地滚阻和发动机制动逐渐减速，漂移时减弱滑行阻力。
- 用 A / D 或 ← / → 转向时按住左 Shift，可锁定当前转向输入，松开方向键仍保持；锁定期间其他方向键不会改变锁定方向。先按左 Shift 时会锁定随后第一次有效转向。松开左 Shift 后恢复当前输入，若方向键也已松开则平滑回正；右 Shift 不触发。暂停、失焦和重置都会清除锁定。锁定的是驾驶输入，车速转角限制与漂移辅助仍然生效。
- S / ↓ 与触控制动从 12% 踏板力度开始，持续按住 0.9 s 线性增加到满力度；松开立即释放并重新计时，连续点按可保持轻刹。手柄 LT 直接使用扳机深度。前进时首先制动；刚体速度低于 0.6 m/s 且持续 0.25 s 后才允许切换倒车驱动，倒车驱动沿用踏板力度。倒车中按 W 也先刹停再换向。静止或低速接地时同时按住 W 与 S 会锁住前轮、驱动后轮烧胎并蓄力；松开 S 后以有限的附加驱动力弹射起步，行驶中同按仍以脚刹力度减速。
- 页面失焦 / 隐藏时清空输入并暂停；恢复可见后需要手动继续。键盘需要重新按下；手柄必须先释放踏板、手刹并让摇杆回中，防止恢复时误加速。Space 用于驾驶手刹并阻止页面滚动；聚焦按钮时可用 Enter 激活按钮。
- 手柄目前仅接受 Gamepad API 的 `standard` 映射，左摇杆有 0.12 死区。触控按钮使用 pointer capture，移出按钮后释放也能正确结束输入。
- F11 或全屏按钮切换驾驶画面全屏；速度、地图等现有 HUD 保持悬浮，并额外显示 WebGPU 后端、FPS、物理步耗时和护栏接触计数。Esc 退出全屏。全屏驾驶中鼠标静止 2.5 s 后隐藏，移动、点击或滚动立即恢复；暂停和退出全屏时恢复可见。F11 依赖浏览器将按键交给页面；被浏览器或系统保留时可使用全屏按钮。
- 横屏且可视高度不超过 600 px 时铺满视口，左侧滑动区提供连续转向，右侧制动、手刹和油门支持多指组合；取消触摸会释放输入。顶部保留视角、全屏与暂停入口，暂停菜单提供赛道选择、重置、音效和画质。屏幕旋转会清空输入并暂停，恢复后需重新操作。安全区适配依赖浏览器提供的 inset 值。
- 重置清空速度、角速度、操控状态、漂移累计时间、练习时间和里程，恢复正常抓地力，将车辆朝赛道方向放回赛道起点，并同步重置地图中的车辆标记，保留当前视角。它不构成有效比赛圈数。
- 低速时同时按住油门、手刹和方向键可动力原地转向；进入速度后持续按住油门、手刹与方向键可保持漂移并持续控制过弯方向。系统只用侧滑速度做有限前轮反打与目标偏航力矩辅助，不会用手刹完全切断驱动力。松开手刹后仍可用油门和方向维持滑行；在已漂移时再次按下手刹或踩脚刹可收车恢复抓地。完整操作、物理边界与验证见 [辅助漂移操控](docs/driving.md)。
- C 按追尾 → 驾驶舱 → 引擎盖 → 保险杠循环。键盘重复事件与持续按住手柄按钮不会连续切换；暂停时也可切换观察。

HUD 显示速度、自动挡位 / R、估算 RPM、油门 / 制动、练习时间与里程、车辆地图位置。地图固定北向上，并按车辆的实际前向与左右转向显示标记；练习总时间独立于圈速 HUD，圈速面板显示当前圈、上圈、最佳圈、有效圈数及下一检查点。赛道、规则与弯道闭环验证见 [赛道与计圈](docs/tracks.md)。高 / 均衡 / 流畅画质分别控制 DPR、阴影、植被细节距离与特效，触控默认均衡；预算及资源说明见 [场景与画质](docs/rendering.md)。引擎诊断可展开查看真实帧数、物理步数、四轮接地状态、护栏接触次数与 CPU 耗时。

动力学 HUD 显示侧滑角、手刹 / 漂移 / 抓地恢复状态与累计漂移时间；诊断面板同时显示后轮抓地系数（相对基准值）、烟雾粒子数与音频状态。左舵驾驶舱保留随转向转动的方向盘，并在嵌入仪表台的实时屏幕显示速度、RPM 和挡位；驾驶舱视角在前风挡上显示无底色的低干扰路线投影。投影使用固定屏幕坐标，不随左右观察或镜头转动而偏移。所有车内视角均压缩 DOM 仪表与地图，避免重复大号仪表遮挡道路。

音量、静音、画质、当前视角及驾驶舱设置保存于本浏览器的本地存储，在刷新、重启引擎和切换赛道后恢复；不会上传或同步到其他设备。暂停面板的驾驶舱设置支持 55°～80° 垂直 FOV、有限的座椅高度及前后位移。Q / E 或画面内观察按钮可按住左右看，松开平滑回正。默认采用偏前的左座驾驶眼点，位于方向盘后上方，视线接近地平线；轻微加减速惯性位移限制在 2.5 cm、自动看弯限制在约 4°，均仅作用于镜头。关闭“轻微惯性、看弯与撞击镜头”可禁用这些附加运动，仍保留车辆真实姿态及手动观察。

声音在首次键盘或点击操作后解锁；顶部与横屏暂停菜单均可调节总音量（默认 35%）或切换静音。暂停或失焦时静音，退出时关闭 AudioContext。发动机基频随 RPM 变化，油门改变音量与滤波，轮胎音随侧滑 / 制动变化，另有风噪和护栏接触音；驾驶舱衰减发动机与风噪。这些是原创 Web Audio 合成音效，并非实车录音。音频不可用不阻止驾驶，可在诊断中查看状态。

## 车辆资产

运行时从本站 `assets/vehicles/car-concept/car.glb` 加载 Car Concept，作者为 Eric Chadwick / Darmstadt Graphics Group GmbH，依据 CC BY 4.0 使用。署名、原始来源、完整许可、模型内商标说明和改动声明见 [CREDITS.md](public/assets/vehicles/car-concept/CREDITS.md)，页面底部也提供链接。部署须包含整个资产目录；不依赖外部模型 CDN。

模型包含完整车身、PBR 纹理、独立轮胎 / 轮毂 / 刹车部件、内饰、方向盘和镜面。预处理把原模型中央控制总成和踏板移到左座，去重、保留动画节点并简化几何，使用 Meshopt 压缩：原始 11,778,688 字节 / 213,347 三角形，输出 5,397,468 字节 / 155,016 三角形。`asset.json` 固定源文件及产物 SHA-256。

`src/vehicle/asset.ts` 定义缩放、底盘偏移、左座位置及四轮节点映射。`VehicleVisual` 校正前轮及方向盘的展示转角并绑定悬挂、转向和滚动；刹车卡钳随转向与悬挂运动但不随车轮滚动。运行时使用青柠 / 炭黑车漆、PBR 环境反射、透明玻璃、制动灯和实时仪表；模型加载失败时可重试。尚未实现距离 LOD 或全车队资源预算。

普通构建直接使用已提交的优化产物。重新生成时，从 CREDITS 中的原始 GLB 地址下载到忽略的 `.asset-cache/car-concept-source.glb`，然后执行 `pnpm assets:vehicle`；自定义来源路径可执行 `node scripts/prepare-vehicle.mjs <源文件路径>`。脚本验证固定源文件哈希，写入 `car.glb` 和 `asset.json`，不修改原始下载；更换来源须先更新授权、节点契约与资产测试。

## 物理与赛道

车辆由 Rapier 动态底盘和官方 `DynamicRayCastVehicleController` 驱动。四条向下射线只查询道路和路肩，排除护栏支点；前轮转向、后轮施加发动机力，普通制动力按固定步长转换为各轮制动冲量。另有空气阻力、接地滚阻、松油发动机制动和简化下压力；低速阻力平滑减小。没有通过逐帧设置位置或旋转来模拟驾驶。

底盘使用外尺寸 1.82×0.46×4.08 m、圆角半径 0.12 m 的简化碰撞体。道路两侧各有 1.6 m 随坡度延伸的支撑路肩，覆盖到护栏外侧，避免贴栏车轮悬空下陷；道路碰撞面启用三角形内部边缘修正。护栏反馈读取 Rapier 接触力，将每步冲量按车重归一化为撞击强度；物理包络覆盖装饰护栏高度并伸入路面下，采用低摩擦、无回弹接触，车体角阻尼和接地姿态力矩抑制轻微侧撞后的起跳与翻转。同一步多段护栏只取最强撞击，重复音效有 0.18 s 间隔。轻擦与重撞具有不同音量，沿墙滑动按切向速度与接触力生成持续摩擦声。撞击可产生最多 32 个短寿命火花和小幅镜头冲击；提示两秒后消退。暂停冻结粒子、静音，重置清空全部反馈；没有车损或车体变形。

每根车轴两轮接地时，按悬挂长度差施加成对防侧倾力，单侧限幅 1800 N。普通驾驶使用接地偏航阻尼；起漂后以实际侧滑速度做受限反打，并以目标侧滑角与实际偏航角速度的误差施加有限偏航力矩，保留驾驶员对过弯半径的控制。低速烧胎时锁住前轮、降低后轮抓地并允许有限原地偏航；松开制动后按蓄力提供受限起步加力。低速、倒车和腾空不启用常规漂移辅助。二次手刹与脚刹触发渐进抓地恢复，重置清空所有漂移状态。实现与参数边界见 [辅助漂移操控](docs/driving.md)。

漂移识别使用车辆纵向与侧向速度：前进超过 5 m/s、至少三轮接地且侧滑超过 9° 时进入，低于 5° 退出。后轮抓地倍率最低 0.48，前轮保持基准抓地；车轮滚动按有效手刹制动显示。尚未实现 Pacejka、胎温、磨损或独立车轮角动量。烟雾池容量 96，接地后轮在漂移或高速手刹时发烟；暂停冻结，重置清空。

`src/vehicle/config.ts` 集中管理物理参数，使用米 / 秒 / 千克：质量 1180 kg、最大扭矩 410 N·m、轮径半径 0.34 m、五个前进挡、重心 / 惯性、悬挂、抓地力、制动力与输入平滑参数。驱动扭矩随 RPM 变化，并随接近速度上限逐渐衰减。自动挡位和 RPM 根据车速 / 传动比估算，未模拟完整离合器、传动轴与差速器动力学。

车辆坐标为 **+Z 前、+Y 上、+X 为驾驶员左侧**。归一化输入正转向表示向右，物理轮转角取反以匹配右手坐标系。固定物理步长 1/60 秒，单渲染帧最多追赶 5 步。渲染插值前后位置与四元数姿态，同时插值轮胎滚动、前轮转向和悬挂长度。追尾镜头按速度拉远，平滑跟随并对固定碰撞体进行射线检测，避免穿入护栏。

`CameraManager` 使用单个输出相机，视角切换在 0.65 秒内平滑插值位置和朝向；连续切换从当前画面位姿继续。相机配置位于 `src/camera/config.ts`，驾驶舱锚点与内饰共用 `src/vehicle/cockpitLayout.ts`，车内视角读取插值后的底盘姿态。过渡中的镜头也检测固定碰撞体；重置车辆时镜头同步归位。第一人称使用程序化左舵内饰，包含连续仪表台、开孔嵌入式实时仪表、A 柱、门板和无模糊三维风挡；路线投影固定于屏幕。原概念车内饰在外部视角恢复。左右外后视镜按车内眼点校准到侧窗外，外部视角恢复原位；镜面没有实时后方画面。结构、坐标和验收方式见 [左舵驾驶舱](docs/cockpit.md)。

`src/track/catalog.ts` 配置试车场、山地、沿海和城市四条闭合路线。`Track` 生成带高差的共用道路、护栏、地图与重置数据；`LapTimer` 使用固定物理步长和八个顺序方向门计圈。道路和护栏参与碰撞，护栏外环境使用 CC0 写实植被 / 岩石 / 路灯、PBR 地表，以及项目内制作的建筑、维修区和金属护栏结构。场景资产来源与加工步骤见 [环境资产说明](public/assets/environment/CREDITS.md)。路线长度、控制器圈时、计圈规则与验证边界见 [赛道与计圈](docs/tracks.md)。

Vue 只消费快照和发送用户指令，不承载每帧物理与渲染。物理世界拥有底盘和车辆控制器，视觉模型独立读取状态。后续方向盘 / 踏板可通过同一 `DriverInput` 契约接入，当前未实现硬件映射。

退出或引擎故障时取消 RAF，移除 ResizeObserver 与输入 / 可见性监听，释放 Rapier 事件队列与世界、场景几何体 / 材质 / 纹理 / 实例化资源 / 阴影、渲染器和自建 GPUDevice，同时停止音频源并关闭 AudioContext。GLB 加载可取消，下载失败或设备错误可从界面重新检测启动，不用占位车掩盖资产失败。

## WebGPU 与依赖边界

显式检查安全上下文和 `navigator.gpu`，依次申请 GPUAdapter、GPUDevice，等待 WebGPURenderer 初始化并核验 `isWebGPUBackend` 以及设备身份。禁止静默回退 WebGL。

Three r187 的构造函数会覆盖传入的 `getFallback`。`StrictWebGPURenderer` 检查并固定实例的 `_getFallback = null`，接口变化即报错。此处是唯一刻意使用的 Three 内部接口；升级依赖必须重新核对并运行后端故障注入测试。

当前锁定 Vue 3.5.45、Vite 8.3.8、Three.js / 类型声明 0.187.0、Rapier 0.21.0。Vue 类型检查器 3.3.14 使用传统编译器入口，因此采用兼容的稳定 TypeScript 6.0.3，而非 TypeScript 7。Rapier 0.21 的前向轴 setter 实际名称为 `setIndexForwardAxis`，实现按随包声明调用。

API 依据为安装版本的官方源码、README 与类型声明。参考：[Three WebGPURenderer](https://threejs.org/docs/pages/WebGPURenderer.html)、[TSL](https://github.com/mrdoob/three.js/wiki/Three.js-Shading-Language)、[Rapier JavaScript 指南](https://rapier.rs/docs/user_guides/javascript/getting_started_js/)、[Vite 指南](https://vite.dev/guide/)。

## 验证与边界

自动化检查覆盖以下行为：

- 30 / 60 / 144 Hz 渲染下固定步数一致，长帧追赶有界。
- 四轮悬挂落地、油门产生加速度、制动先于倒车、倒车限速、反向换挡和转向符号。
- 平滑转向、刚体与插值状态重置、持续油门撞护栏无法穿越。
- 开放平面上用相同输入对比正常过弯和手刹侧滑；检查抓地渐进恢复、反打后保持前进、手刹停车不倒车、横向滑动时不提前换倒挡、重置清除漂移、高速稳定与落地收敛。
- 四视角的连续切换、快速重复切换、底盘旋转后的相机朝向、窄屏比例以及镜头被固定护栏遮挡时的位置。
- 使用归一化油门 / 转向输入自动驾驶完整闭合赛道，检查无护栏接触且始终位于赛道内；这不是游戏内自动驾驶功能，也不是人工驾驶手感评价。
- 缺少 GPU、适配器 / 设备申请失败及后端初始化失败均不触发 WebGL；设备丢失和未捕获 GPU 错误会释放资源并允许重启。
- 实际浏览器中的键盘驾驶、倒车、暂停、重置、失焦输入清理、DPR / 窄屏与触控按下释放；标准手柄映射和回中锁通过模拟输入测试。
- GLB 校验和、自包含纹理、左舵 / 四轮节点绑定、刹车灯及全部 PBR 纹理释放；模型下载失败与重试。
- 烟雾容量上限、寿命到期与腾空车轮不发烟。
- 真实 AudioContext 的手势解锁、转速驱动频率、静音 / 暂停、初始化失败与退出关闭；音色仍需人工试听。
- 实际 WebGPU 手刹侧滑、烟雾生成与重置、四视角渲染截图、暂停中切换、触控手刹取消；标准手柄手刹与相机按钮的边沿触发、释放回中锁。
- 667×375 / 844×390 横屏控制区可见性、多触点转向与踏板组合、手刹取消和暂停入口。

验收环境为 Windows / Chrome / WebGPU（本轮为 Intel gen-9），没有添加强制 GPU 或忽略显卡黑名单的参数。浏览器驾驶检查控制台错误并生成桌面、窄屏截图至忽略的 `test-results/`。物理与输入测试通过不能代替真实玩家对手感的评价；实体手柄、其他 GPU / 浏览器、真实移动设备与长时间内存稳定性仍需验收。

物理 CPU 指标为最近一次车辆控制与世界固定步耗时，渲染 CPU 指标是提交耗时，**均不代表 GPU 执行时间**。尚未做 GPU 时间戳分析或完整游戏性能优化。Rapier compat 内嵌 WASM，使引擎 JS 分块约 5.3 MB（gzip 约 1.93 MB）；构建保留较大分块提示，尚未独立托管 WASM。
