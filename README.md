# APEX / Racing Lab

高品质 WebGPU 赛车项目，已实现车辆动力学，并接入正式授权的 **Car Concept GLB 赛车、左舵驾驶舱、轮胎烟雾与驾驶音效**。在约 0.95 km 的松岭闭合试车场自由驾驶，支持手刹侧滑、渐进抓地恢复、悬挂防侧倾与四种视角。当前仍是驾驶体验，三条主题赛道与完整比赛流程尚未实现。

## 运行

需要 Node.js 20.19+（22.x 需 22.12+）、pnpm 11.18.0，以及支持 WebGPU、开启硬件加速的现代浏览器。开发使用 localhost / 127.0.0.1，正式部署使用 HTTPS。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端给出的本地地址，默认 `http://127.0.0.1:5173`。

```sh
pnpm build          # Vue / TypeScript 类型检查 + 生产构建
pnpm preview        # 本地预览 dist，默认端口 4173
pnpm test           # 物理、闭环驾驶、输入与真实 WebGPU 浏览器验收
pnpm format:check   # 格式检查
```

测试默认使用已安装的 Google Chrome。使用 Edge 时在 PowerShell 设置 `$env:BROWSER_CHANNEL = 'msedge'` 后运行 `pnpm test`。测试会启动或复用 5173 端口的开发服务；本地请求不经过 HTTP 代理。没有 WebGPU 的环境会使实际渲染测试失败，不会跳过或回退 WebGL。

依赖使用精确版本和 `pnpm-lock.yaml` 固定。`pnpm-workspace.yaml` 管理工作区内的 `.pnpm-cache/`、`.pnpm-store/`，二者不纳入 Git。没有服务端、数据库、环境变量式游戏配置或外部模型 / 字体 CDN。`dist/` 可作为静态站点通过 HTTPS 托管，并应启用 gzip / Brotli。

## 驾驶操作

| 操作               | 键盘             | 标准映射手柄 | 触控            |
| ------------------ | ---------------- | ------------ | --------------- |
| 加速               | W / ↑            | RT           | 按住加速        |
| 制动，停稳后倒车   | S / ↓            | LT           | 按住制动 / 倒车 |
| 转向               | A、D / ←、→      | 左摇杆       | 按住左右箭头    |
| 手刹               | Space            | A（按钮 0）  | 按住手刹        |
| 循环切换视角       | C                | X（按钮 2）  | 顶部视角按钮    |
| 回到最近的赛道中心 | R / 重置车辆按钮 | Y            | 重置车辆按钮    |
| 暂停 / 继续        | Esc / 暂停按钮   | Start        | 暂停 / 继续按钮 |

- 输入有持续按下和释放状态，转向与油门经过平滑处理。车速越高，最大转向角越小。
- S 在前进时首先制动；刚体速度低于 0.6 m/s 且持续 0.25 s 后才允许切换倒车驱动。倒车中按 W 也先刹停再换向。油门与制动同时按下时制动优先。
- 页面失焦 / 隐藏时清空输入并暂停；恢复可见后需要手动继续。键盘需要重新按下；手柄必须先释放踏板、手刹并让摇杆回中，防止恢复时误加速。Space 用于驾驶手刹并阻止页面滚动；聚焦按钮时可用 Enter 激活按钮。
- 手柄目前仅接受 Gamepad API 的 `standard` 映射，左摇杆有 0.12 死区。触控按钮使用 pointer capture，移出按钮后释放也能正确结束输入。
- 横屏且可视高度不超过 600 px 时铺满视口，左侧滑动区提供连续转向，右侧制动、手刹和油门支持多指组合；取消触摸会释放输入。顶部保留视角与暂停入口，暂停菜单提供重置、音效和画质。屏幕旋转会清空输入并暂停，恢复后需重新操作。安全区适配依赖浏览器提供的 inset 值。
- 重置清空速度、角速度、操控状态、漂移累计时间、练习时间和里程，恢复正常抓地力，将车辆朝赛道方向放回最近的中心点，保留当前视角。它不构成有效比赛圈数。
- 手刹只制动后轮并减小后轮抓地力，同时切断相应比例的后轮驱动力；不会触发倒挡。入弯前减速，转向时短按手刹，松开后适度反打并控制油门恢复抓地。持续按住手刹可能导致停车或甩尾。
- C 按追尾 → 驾驶舱 → 引擎盖 → 保险杠循环。键盘重复事件与持续按住手柄按钮不会连续切换；暂停时也可切换观察。

HUD 显示速度、自动挡位 / R、估算 RPM、油门 / 制动、练习时间与里程、车辆地图位置。计时是自由练习时间，不是圈速。画质选项控制 DPR 上限为 2 或 1。引擎诊断可展开查看真实帧数、物理步数、四轮接地状态、护栏接触次数与 CPU 耗时。

动力学 HUD 显示侧滑角、手刹 / 漂移 / 抓地恢复状态与累计漂移时间；诊断面板同时显示后轮抓地系数（相对基准值）、烟雾粒子数与音频状态。左舵驾驶舱有随转向转动的方向盘，以及显示速度、RPM 和挡位的实时屏幕。所有车内视角均压缩 DOM 仪表与地图，避免重复大号仪表遮挡道路。

暂停面板的驾驶舱设置支持 55°～80° 垂直 FOV、有限的座椅高度及前后位移；设置在本次页面会话和引擎重启中保留，不写入浏览器存储。Q / E 或画面内观察按钮可按住左右看，松开平滑回正。默认眼点略后移并抬高、视线更接近地平线；轻微加减速惯性位移限制在 2.5 cm、自动看弯限制在约 4°，均仅作用于镜头。关闭“轻微惯性、看弯与撞击镜头”可禁用这些附加运动，仍保留车辆真实姿态及手动观察。

声音在首次键盘或点击操作后解锁，顶部按钮切换静音；暂停或失焦时静音，退出时关闭 AudioContext。发动机基频随 RPM 变化，油门改变音量与滤波，轮胎音随侧滑 / 制动变化，另有风噪和护栏接触音；驾驶舱衰减发动机与风噪。这些是原创 Web Audio 合成音效，并非实车录音。音频不可用不阻止驾驶，可在诊断中查看状态。

## 车辆资产

运行时从本站 `assets/vehicles/car-concept/car.glb` 加载 Car Concept，作者为 Eric Chadwick / Darmstadt Graphics Group GmbH，依据 CC BY 4.0 使用。署名、原始来源、完整许可、模型内商标说明和改动声明见 [CREDITS.md](public/assets/vehicles/car-concept/CREDITS.md)，页面底部也提供链接。部署须包含整个资产目录；不依赖外部模型 CDN。

模型包含完整车身、PBR 纹理、独立轮胎 / 轮毂 / 刹车部件、内饰、方向盘和镜面。预处理把原模型中央控制总成和踏板移到左座，去重、保留动画节点并简化几何，使用 Meshopt 压缩：原始 11,778,688 字节 / 213,347 三角形，输出 5,397,468 字节 / 155,016 三角形。`asset.json` 固定源文件及产物 SHA-256。

`src/vehicle/asset.ts` 定义缩放、底盘偏移、左座位置及四轮节点映射。`VehicleVisual` 校正前轮及方向盘的展示转角并绑定悬挂、转向和滚动；刹车卡钳随转向与悬挂运动但不随车轮滚动。运行时使用青柠 / 炭黑车漆、PBR 环境反射、透明玻璃、制动灯和实时仪表；模型加载失败时可重试。尚未实现距离 LOD 或全车队资源预算。

普通构建直接使用已提交的优化产物。重新生成时，从 CREDITS 中的原始 GLB 地址下载到忽略的 `.asset-cache/car-concept-source.glb`，然后执行 `pnpm assets:vehicle`；自定义来源路径可执行 `node scripts/prepare-vehicle.mjs <源文件路径>`。脚本验证固定源文件哈希，写入 `car.glb` 和 `asset.json`，不修改原始下载；更换来源须先更新授权、节点契约与资产测试。

## 物理与赛道

车辆由 Rapier 动态底盘和官方 `DynamicRayCastVehicleController` 驱动。四条向下射线计算悬挂接触，前轮转向、后轮施加发动机力；普通制动力按固定步长转换为各轮制动冲量。另有空气阻力和接地时的简化下压力。没有通过逐帧设置位置或旋转来模拟驾驶。

底盘使用外尺寸 1.82×0.46×4.08 m、圆角半径 0.12 m 的简化碰撞体。护栏反馈读取 Rapier 接触力，将每步冲量按车重归一化为撞击强度；同一步多段护栏只取最强撞击，重复音效有 0.18 s 间隔。轻擦与重撞具有不同音量，沿墙滑动按切向速度与接触力生成持续摩擦声。撞击可产生最多 32 个短寿命火花和小幅镜头冲击；提示两秒后消退。暂停冻结粒子、静音，重置清空全部反馈；没有车损或车体变形。

每根车轴两轮接地时，按悬挂长度差施加成对防侧倾力，单侧限幅 1800 N；至少三轮接地且绝对纵向速度超过 5 m/s 时，用偏航阻尼力矩限制过快旋转。辅助强度随后轮抓地倍率在 35%～100% 间连续变化，松手刹不会立即跳回完整辅助。腾空时不施加上述稳定辅助。悬挂着地、落地收敛和高速连续左右转向均有独立物理测试。

`DriftController` 将刚体速度投影到车辆前 / 左轴，计算侧滑角。前进超过 5 m/s、至少三轮接地且侧滑超过 9° 时计入漂移，低于 5° 退出，避免阈值抖动；倒车、静止与腾空不累计漂移。手刹将后轮摩擦与侧向刚度的倍率平滑降至最低 0.48，前轮保持基准抓地。释放后按指数曲线恢复；已有侧滑时油门保留少量后轮滑动，反打加快恢复。侧向运动来自 Rapier 轮胎冲量，不添加人为横移或姿态旋转。

这是基于 Rapier 摩擦参数的街机操控模型，未实现 Pacejka、胎温、磨损或独立车轮角动量；后轮视觉滚动在手刹下减慢至锁止。烟雾使用容量为 96 的实例化粒子池，在漂移或高速手刹时从接地后轮发出，在世界空间扩散消散；腾空车轮不发烟，暂停冻结、重置清空。

侧滑中的有效反打采用更快的转向响应，并按侧滑角最多增加 30% 转角余量，仍受低速最大转角限制；倒车、腾空及正常过弯不启用这项余量。手刹切断驱动力后，松开以约 0.38 s 达到 90% 的速率渐进恢复驱动力；这是驱动力包络，并非完整离合器仿真。油门保留侧滑的抓地变化在低速与侧滑退出阈值处连续过渡。调校回归覆盖 40 / 60 / 90 km/h 短按手刹与反打恢复；持续控漂及左右接漂仍需玩家主观验收。

`src/vehicle/config.ts` 集中管理物理参数，使用米 / 秒 / 千克：质量 1180 kg、最大扭矩 410 N·m、轮径半径 0.34 m、五个前进挡、重心 / 惯性、悬挂、抓地力、制动力与输入平滑参数。驱动扭矩随 RPM 变化，并随接近速度上限逐渐衰减。自动挡位和 RPM 根据车速 / 传动比估算，未模拟完整离合器、传动轴与差速器动力学。

车辆坐标为 **+Z 前、+Y 上、+X 为驾驶员左侧**。归一化输入正转向表示向右，物理轮转角取反以匹配右手坐标系。固定物理步长 1/60 秒，单渲染帧最多追赶 5 步。渲染插值前后位置与四元数姿态，同时插值轮胎滚动、前轮转向和悬挂长度。追尾镜头按速度拉远，平滑跟随并对固定碰撞体进行射线检测，避免穿入护栏。

`CameraManager` 使用单个输出相机，视角切换在 0.65 秒内平滑插值位置和朝向；连续切换从当前画面位姿继续。相机锚点集中在 `src/camera/config.ts`，车内视角读取插值后的底盘姿态。过渡中的镜头也检测固定碰撞体；重置车辆时镜头同步归位。车内保留真实车身、A 柱、内饰和后视镜，仅在驾驶舱视角隐藏玻璃，避免多层透明表面影响视线；左座眼点与方向盘、仪表对齐。后视镜目前是模型表面，没有实时后方画面。

`src/track/Track.ts` 中的闭合 Catmull-Rom 中心线生成 240 个等距采样，供 16 m 宽道路、路肩、护栏、碰撞体、地图和重置点共用。道路为三角网格碰撞，连续护栏采用重叠的固定盒形碰撞体。场景中的植被、山体和建筑为隔离在护栏外的装饰物，不创建复杂碰撞体。当前测试赛道为平面原型，约 0.95 km；正式赛道的坡度、检查点和约三分钟圈速目标属于后续阶段。

Vue 只消费快照和发送用户指令，不承载每帧物理与渲染。物理世界拥有底盘和车辆控制器，视觉模型独立读取状态。后续方向盘 / 踏板可通过同一 `DriverInput` 契约接入，当前未实现硬件映射。

退出或引擎故障时取消 RAF，移除 ResizeObserver 与输入 / 可见性监听，释放 Rapier 事件队列与世界、场景几何体 / 材质 / 纹理 / 实例化资源 / 阴影、渲染器和自建 GPUDevice，同时停止音频源并关闭 AudioContext。GLB 加载可取消，下载失败或设备错误可从界面重新检测启动，不用占位车掩盖资产失败。

## WebGPU 与依赖边界

显式检查安全上下文和 `navigator.gpu`，依次申请 GPUAdapter、GPUDevice，等待 WebGPURenderer 初始化并核验 `isWebGPUBackend` 以及设备身份。禁止静默回退 WebGL。

Three r187 的构造函数会覆盖传入的 `getFallback`。`StrictWebGPURenderer` 检查并固定实例的 `_getFallback = null`，接口变化即报错。此处是唯一刻意使用的 Three 内部接口；升级依赖必须重新核对并运行后端故障注入测试。

当前锁定 Vue 3.5.45、Vite 8.3.8、Three.js / 类型声明 0.187.0、Rapier 0.21.0。Vue 类型检查器 3.3.14 使用传统编译器入口，因此采用兼容的稳定 TypeScript 6.0.3，而非 TypeScript 7。Rapier 0.21 的前向轴 setter 实际名称为 `setIndexForwardAxis`，实现按随包声明调用。

API 依据为安装版本的官方源码、README 与类型声明。参考：[Three WebGPURenderer](https://threejs.org/docs/pages/WebGPURenderer.html)、[TSL](https://github.com/mrdoob/three.js/wiki/Three.js-Shading-Language)、[Rapier JavaScript 指南](https://rapier.rs/docs/user_guides/javascript/getting_started_js/)、[Vite 指南](https://vite.dev/guide/)。

## 验证与边界

自动化检查覆盖以下行为：

- 30 / 60 / 144 Hz 渲染下固定步数一致，长帧追赶有界。
- 四轮悬挂落地、油门产生加速度、制动先于倒车、倒车限速、反向换挡和转向符号。
- 平滑转向、刚体与插值状态重置、持续油门撞护栏无法穿越。
- 开放平面上用相同输入对比正常过弯和手刹侧滑；检查抓地渐进恢复、反打后保持前进、手刹停车不倒车、横向滑动时不提前换倒挡、重置清除漂移、高速稳定与落地收敛。
- 四视角的连续切换、快速重复切换、底盘旋转后的相机朝向、窄屏比例以及镜头被固定护栏遮挡时的位置。
- 使用归一化油门 / 转向输入自动驾驶完整闭合赛道，检查无护栏接触且始终位于赛道内；这不是游戏内自动驾驶功能，也不是人工驾驶手感评价。
- 缺少 GPU、适配器 / 设备申请失败及后端初始化失败均不触发 WebGL；设备丢失和未捕获 GPU 错误会释放资源并允许重启。

- 667×375 / 844×390 横屏控制区可见性、多触点转向与踏板组合、手刹取消和暂停入口。

验收环境为 Windows / Chrome / NVIDIA Pascal WebGPU，没有添加强制 GPU 或忽略显卡黑名单的参数。浏览器驾驶检查控制台错误并生成桌面、窄屏截图至忽略的 `test-results/`。物理与输入测试通过不能代替真实玩家对手感的评价；实体手柄、其他 GPU / 浏览器、真实移动设备与长时间内存稳定性仍需验收。

物理 CPU 指标为最近一次车辆控制与世界固定步耗时，渲染 CPU 指标是提交耗时，**均不代表 GPU 执行时间**。尚未做 GPU 时间戳分析或完整游戏性能优化。Rapier compat 内嵌 WASM，使引擎 JS 分块约 5.29 MB（gzip 约 1.93 MB）；构建保留较大分块提示，尚未独立托管 WASM。
